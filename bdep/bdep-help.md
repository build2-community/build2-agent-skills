# bdep-help -- show help for a command or help topic

## Synopsis

```
bdep help [<command> | <topic>]
```

## Description

Show the detailed help for `<command>` or help `<topic>`, or print a summary
of all available commands and topics if none is specified.

## Default Options Files

The following options files are searched for only in the predefined
directories (home, system, etc.) and, if found, loaded in the order listed:

```
bdep.options
bdep-help.options
```
